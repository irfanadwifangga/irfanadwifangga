# Hi, I'm Irfana Dwi Fangga 👋

Fullstack Developer from Indonesia, focused on Next.js/TypeScript on the frontend and Prisma, Django, and PostgreSQL on the backend. I like building the parts of a product that are easy to get wrong — payment flows, real-time integrations, and admin systems that have to stay correct under concurrency.

- **Freelance Fullstack Developer @ Seria** — building a full digital ecosystem for a Minecraft server community: the main website, an admin CMS, a payment-integrated webstore (Duitku — VA/e-wallet/QRIS), and a custom Java plugin that bridges the web backend to the game server in real time via RCON.
- **Freelance Fullstack Developer @ GM Workspace** — building an internal management platform for a YouTube content team: automated payroll, a tiered bonus engine driven by video view counts, Google Drive integration, and server-side PDF generation for invoices and slips.
